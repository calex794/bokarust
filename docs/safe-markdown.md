# BKR-86 — безопасная разметка главы

Реализация без новых библиотек в Rust: [safe_markdown.rs](https://github.com/calex794/bokarust/blob/feat/bkr86-safe-markdown/crates/web/src/safe_markdown.rs). Действующий пользовательский сценарий: [В2.05](https://app.notion.com/p/3f632a84beec8196aaf3f72659929216); соответствие исходному Booka не заявляется без отдельных тестов.

## Разрешённая разметка

- Заголовки `#`…`######`, обычные абзацы.
- **Жирное**, *курсив*, встроенный и многострочный программный текст.
- Обычные маркированные и нумерованные списки, цитаты.
- Ссылки только с `https://`, `http://`, внутренними адресами `/...` (не `//...`) и локальными якорями `#...`. Внешние ссылки с `rel="nofollow noopener noreferrer"`.
- Вложенные списки, таблицы, изображения, произвольный HTML, дополнительные возможности CommonMark пока не интерпретируются; нераспознанный синтаксис отображается текстом. Это **ограниченный набор Markdown**, а не полный CommonMark.

## Безопасность

- Весь пользовательский текст проходит HTML-экранирование; HTML-теги источника не исполняются. Адреса ссылок отдельно проверяются по разрешённым схемам, управляющие символы/пробелы/опасные кавычки не принимаются.
- Максимальный размер текста главы остаётся 50 000 символов по существующему ограничению. Поиск закрывающих маркеров ограничен 2048 байтами, вложенность форматирования — 6, чтобы повреждённый исходник не давал неограниченного обхода.
- У открытой `/reader/{id}` установлен заголовок `Content-Security-Policy` с запретом скриптов. Личная `/read/{id}` сохраняет прежнее разрешение только локального скрипта автосохранения, без встроенных скриптов. Доступ к главе перепроверяется независимо от HTML.
- Нет загрузки изображений или внешних библиотек. Страница остаётся доступна без JavaScript.

## Сохранение точного места

- Разделение на не более 200 неизменяемых блоков и сохранённый в PostgreSQL `char_offset` **не меняются**. Разметка на Rust добавляет к видимым текстовым участкам `data-md-start` — смещение соответствующего исходного текста в UTF-16 единицах.
- Скрипт автосохранения учитывает исходный адрес участка, а при повторном открытии ищет ближайший видимый участок в том же блоке. Для обычного текста точное положение совпадает; если закладка попала на скрытый символ Markdown (`**`, `#`, скобки ссылки), восстанавливается ближайшее видимое место.
- При изменении опубликованной версии старое положение по-прежнему считается устаревшим; старые запросы не могут сдвинуть место назад. В браузере без вычисления позиции остаётся сохранение на уровне блока.

## Проверки

- Rust: визуальные элементы, кириллица и исходные UTF-16 смещения, HTML и JavaScript в тексте, запрещённые схемы/опасные атрибуты, ограничение 50 000 символов.
- Node без новых пакетов: видимый текст после разметки корректно переводится в UTF-16 позицию, старое место восстанавливается, чужой текст за пределами блока не засчитывается; старые проверки задержек, гонок и ухода со страницы сохраняются.
- Реальные HTTP/PostgreSQL проверки: обе версии читалки форматируют допустимые ссылки и разметку, не выдают опасный HTML, у публичной страницы скрипты запрещены, права на закрытые/платные версии остаются прежними.
- Выпускается только после зелёных обязательных проверок GitHub. Не расширять задачи на покупку глав и редактор.
