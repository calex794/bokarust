# BookaRust — прототип редактора глав

Изолированный эксперимент NEwBOO на Rust. Исходный [booka](https://github.com/calex794/booka) не затронут.

## Что реализовано

- **Rust + Leptos + WebAssembly:** обычное поле ввода, выделение, кнопки Markdown, предпросмотр, показ несохранённых изменений, генерация тестовых глав на 5, 10, 20 и 50 тыс. символов. Образцы 150 тыс. и 1 млн предназначены только для испытаний нагрузки.
- **Axum:** `GET /api/chapter`, `PUT /api/chapter`; запись в `chapter.json`, проверка номера редакции, хеш текста, отсутствие новой редакции при повторном сохранении. Сервер принимает главы длиной **не более 50 000 символов**, включая ровно 50 000.
- **Проверки:** `cargo test --workspace` проверяет нормализацию и границы в 50 000/50 001 символ, включая кириллицу и эмодзи; `trunk build --release` собирает браузерную часть.

## Запуск локально

Требуются Rust (stable), установленная цель `wasm32-unknown-unknown` и [Trunk](https://trunkrs.dev/).

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk --locked
cargo test --workspace
trunk build
cargo run -p editor-server
```

Открыть http://127.0.0.1:8080 . Сервер отдаёт собранные файлы из `dist`. Для разработки можно запустить `trunk serve` в отдельном окне, но указанный выше вариант проще.

## Не готово к использованию в открытом интернете

**Только локальный опытный образец:** нет авторизации, разграничения прав, CSRF, базы PostgreSQL, защиты от параллельных процессов, защиты от внешних ссылок на картинки и сохранения полноценных интерактивных сцен. Загружать личные/производственные тексты нельзя. Указатель несохранённых изменений — визуальный, подтверждение закрытия окна не реализовано.

Средний ожидаемый объём главы — 5–10 тыс. символов. Проверочные образцы на 150 тыс. и 1 млн не могут сохраняться как главы. Реальные замеры Chromium и сравнение с EasyMDE проведены, но Firefox/WebKit, настоящая системная клавиатура IME и слабые телефоны пока не проверены.
