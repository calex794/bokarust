# BookaRust

Новая независимая реализация NEwBOO на Rust. Исходный `booka` используется только как образец.

## PostgreSQL для каталога

Для работы с настоящими данными нужен PostgreSQL 18. Сервер применяет единый набор версионированных миграций из `crates/adapters/migrations/` (учётные записи, сеансы, книги) до начала приёма запросов. Секреты не хранить в Git.

```bash
export DATABASE_URL="postgres://bokarust:YOUR_PASSWORD@127.0.0.1:5432/bokarust"
cargo run -p bokarust-web
```

Без `DATABASE_URL` сервер не запускается, кроме явно разрешённого демонстрационного режима `BOKARUST_DEMO_IN_MEMORY=1` на обратной петле. `/healthz` показывает только работу процесса, а не готовность базы. При недоступности БД каталог отвечает 503, не раскрывая черновики. [Контракт каталога](docs/architecture/postgres-catalog.md) и [учётные записи](docs/database/accounts.md).

## Первый модульный каркас

Код организован как модульный монолит: `domain`, `application`, `adapters` и `web`. Для публичного каталога используется PostgreSQL; хранилище в памяти осталось только для явной локальной демонстрации.

```bash
cargo fmt --all -- --check
cargo test --workspace               # без дополнительных инструментов
cargo nextest run --profile ci       # при установленном cargo-nextest
BOKARUST_DEMO_IN_MEMORY=1 cargo run -p bokarust-web  # локальная демонстрация
```

Адреса после запуска:
- `http://127.0.0.1:3000/healthz` — проверка процесса, не проверка БД.
- `http://127.0.0.1:3000/api/v1/books` — публичный каталог из PostgreSQL (пустой в демонстрационном режиме).

Подробности: [модульная архитектура](docs/architecture/modular-foundation.md).

## Первые веб-страницы

Существующий сервер Axum теперь отдаёт HTML и таблицу стилей, не требуя Python или JavaScript:

- `/` — главная с меню и публичными книгами;
- `/catalog` — каталог из существующего `ListPublicBooks` (PostgreSQL);
- `/login` и `/register` — **только предварительный вид форм**, ввод и отправка отключены до реализации веб-авторизации и безопасных сеансов;
- `/assets/site.css` — таблица стилей. Макеты рассчитаны и на узкие экраны.

Маршруты публичных страниц не показывают черновики, а динамические названия книг экранируются перед вставкой в HTML. Формы ещё не принимают данные и не создают учётные записи. Следующая задача: подключить регистрацию, вход и кабинет к уже созданному PostgreSQL-хранилищу учётных записей.

## Границы продукта

**Интерактивные сцены и их магазин заморожены** решением владельца от 11.10.2026. Не реализуем на Rust старый редактор сцен, их читалку, пресеты, студию персонажей, лицензирование и продажи сцен. Эти функции не являются условием первого выпуска. Обычные книги, Markdown-главы и их публикация остаются в работе.

См. [подробное решение о границах текущей разработки](docs/product-scope.md).

## Проверки и ветки

- [PR #2 — архитектурные проверки и ограничения CI](https://github.com/calex794/bokarust/pull/2) уже объединён в `main`.
- [PR #3 — модульный каркас](https://github.com/calex794/bokarust/pull/3) содержит работающий сквозной путь и быстрый отбор Rust-тестов по обратным зависимостям. Тесты запускаются с ограничением времени и завершаются при ошибке.
- [PR #1 — прототип редактора Rust + Leptos](https://github.com/calex794/bokarust/pull/1) остаётся самостоятельной работой и пока не подключён к основному серверу.

Полный набор тестов настроен на ежедневную проверку. Для изменений только документации Rust-тесты не требуются; для общих и неизвестных изменений запускаются все. Подробности: [правила архитектуры](docs/architecture/README.md).

Новый веб-сервер **не готов** для публичного размещения: реализовано только чтение каталога из PostgreSQL; нет записи книг через сайт, веб-авторизации и подтверждённой безопасности всего приложения.
