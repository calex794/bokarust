# BookaRust — прототип редактора глав

Изолированный эксперимент NEwBOO на Rust. Исходный [booka](https://github.com/calex794/booka) не затронут.

## Что реализовано

- **Rust + Leptos + WebAssembly:** обычное поле ввода, выделение, кнопки Markdown, предпросмотр, показ несохранённых изменений, генерация текстов 20 тыс. / 150 тыс. / 1 млн символов.
- **Axum:** `GET /api/chapter`, `PUT /api/chapter`; запись в `chapter.json`, проверка номера редакции, хеш текста и отсутствие создания новой редакции при повторном сохранении.
- **Проверки:** `cargo test --workspace` проверяет нормализацию, валидацию и сохранность текста на трёх больших размерах, `trunk build --release` собирает браузерную часть.

## Запуск локально

Требуются Rust (stable), установленная цель `wasm32-unknown-unknown` и [Trunk](https://trunkrs.dev/).

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk --locked
cargo test --workspace
trunk build
cargo run -p editor-server
```

Открыть http://127.0.0.1:8080 . Сервер отдаёт собранные файлы из `dist`. Для разработки можно запустить `trunk serve` в отдельном окне, но указанный выше вариант проще.

## Не готово к использованию в открытом интернете

**Только локальный опытный образец:** нет авторизации, разграничения прав, CSRF, базы PostgreSQL, защиты от параллельных процессов, защиты от внешних ссылок на картинки и сохранения полноценных интерактивных сцен. Загружать личные/производственные тексты нельзя. Указатель несохранённых изменений — визуальный, подтверждение закрытия окна не реализовано.

Наличие образцов длиной до миллиона символов и теста ядра **не означает**, что скорость ввода в браузере измерена. Нужны реальные испытания Chromium/Firefox/WebKit на разных устройствах, в том числе Ctrl+Z, IME, выделение с эмодзи и загрузка больших файлов.

См. [архитектуру и план в Notion](https://app.notion.com/p/3f632a84beec81db9bdec4ef9718ae96).
